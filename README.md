# Parejas del Monte

Juego de memoria con cartas de animales y plantas del monte. Das la vuelta a dos cartas y, si son iguales, se quedan boca arriba.

- Tres niveles: fácil (6 parejas), normal (8) y difícil (12).
- Cuenta intentos y tiempo, y guarda el récord de intentos por nivel en el navegador.
- Tema claro y oscuro según el sistema.

Es una sola página (`index.html`), sin dependencias ni paso de compilación. Para jugar en local, abre el archivo en el navegador.

Demo: https://andresrubio.github.io/parejas-del-monte/
